ATELIER DU CHRONOPHONE

Fabriquez votre propre machine : vos leviers, vos photos ou vos textes, vos réponses, votre message final.

Réglez la machine ci-dessous, cliquez Essayer le jeu pour la tester, puis Télécharger le jeu : vous obtenez un seul fichier .html à ouvrir dans un navigateur, à déposer sur l'ENT ou sur un site. Votre travail est gardé automatiquement dans ce navigateur. Pensez aussi à Enregistrer la configuration pour pouvoir la modifier plus tard ailleurs.

1. Les leviers

Ce qui s'affiche en haut et en bas de chaque levier. Les élèves placent chaque levier en haut ou en bas, puis abaissent la manette rouge. Le nombre de leviers se choisit dans la partie 2.

2. Les questions (un levier par question)

A Combien de questions ?
leviers (de 2 à 40). Les cases à remplir apparaissent en dessous.
ou, si vos questions sont déjà écrites dans un document :
B Remplissez chaque case
  1. Écrivez la question dans la zone claire, ou cliquez Mettre une photo.
  2. Type de réponse : « Deux réponses » (haut / bas, réglés dans la partie 1) ou QCM A-D. Pour un QCM, écrivez aussi les choix A, B, C… sous la question.
  3. Cliquez la bonne réponse : elle s'allume en couleur.
Comment écrire le document pour l'import automatique ?
Une question par paragraphe, les choix sur les lignes suivantes, la bonne réponse indiquée si vous voulez : 1. Quel réglage protège le mieux ton compte ? A) Un mot de passe court et facile B) La double authentification * C) Le même mot de passe partout 2. Une photo publiée peut-elle être effacée d'Internet pour toujours ? Réponse : non • Une question avec des choix A, B, C, D devient un QCM. • Une question sans choix devient un levier à deux réponses (haut et bas). • Bonne réponse : une étoile * après le choix, ou une ligne « Réponse : B » (ou oui, non, vrai, faux). • Fichiers acceptés : Word (.docx), PDF avec du texte, texte (.txt). Un PDF scanné en image ne peut pas être lu.
